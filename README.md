# Full code for the paper "Evidence-Grounded Multimodal Mining of Fine-Grained Research Problems and Methods from Computer Vision Papers"

## Dataset
The dataset used in this paper is available at https://pan.baidu.com/s/1iW_PJn8NwLIb4GZK9kZLCg?pwd=i8nw  Just replace the "data" folder.  
MinerU-processed literature data is saved in the data/output directory, with each paper in a separate subfolder containing a Markdown file and an image folder.

## Run Code
1.Save your Qwen-VL API key to the qwen_key.txt file.


2.`python scripts/run_revision_experiments.py --root-dir data/output --start 1 --end 100 --conditions added_chunk_6000 --model qwen-vl-max --overlap-chars 900 --max-images-per-chunk 4 --request-timeout 1200 --max-retries 5 --max-tokens 8192 --temperature 0.1 --skip-existing`

The script reads all the papers in the data/output directory and processes them iteratively. The results generated by our method will be saved in the data/output folder, with each paper stored in its corresponding subfolder.  
This process generates three files (01_l1_chunk_results.json, 02_evidence_index.json, and 04_final_extraction.json), which serve as the data for our Problem-Method Graph.  


3.Problem-Method Graph Visualization  


To open the Problem-Method Graph visualization interface, double-click the `journal_figure.html` file in the result_visualizer directory. Then, click "Final JSON" to `select 04_final_extraction.json`, click "L1 JSON" to select `01_l1_chunk_results.json`, click "Evidence Index" to select `02_evidence_index.json`, and finally, click "Images Folder" to select the image folder parsed by MinerU.

## Quantitative Evaluation

The extraction command does not directly aggregate the NET, AMG, ESGC, TLP, EGMR, and BEGQ metrics.

After completing extraction, run the following command to calculate the structural metrics over all 100 papers:

```bash
python scripts/aggregate_batch_metrics.py --root-dir data/output --start 1 --end 100 --conditions added_chunk_6000 --output-dir data/output/aggregate_metrics_added_chunk_6000
```

The main output files are:

```text
data/output/aggregate_metrics_added_chunk_6000/metrics_summary_core.csv
data/output/aggregate_metrics_added_chunk_6000/metrics_summary.csv
data/output/aggregate_metrics_added_chunk_6000/metrics_summary_core_latex.tex
```

The `metrics_summary_core.csv` file reports the following metrics:

* NET
* AMG
* ESGC
* TLP
* EGMR
* BEGQ

To calculate Problem, Method, and Relation precision, recall, and F1 scores against the human-reviewed reference annotations for the first 30 papers, run:

```bash
python scripts/run_quantitative_pipeline.py --root-dir data/output --start 1 --end 30 --conditions added_chunk_6000 --output-dir data/output/revision_metrics/added_chunk_6000
```

The main semantic evaluation results are written to:

```text
data/output/revision_metrics/added_chunk_6000/summary.csv
```
